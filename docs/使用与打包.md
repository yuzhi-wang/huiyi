## HBuilderX 打开与打包

1. 文件 → 导入 → 从本地目录导入，选择包含 `manifest.json`、`main.js` 的项目根目录。
2. 使用已登录的 DCloud 账号，在 [DCloud 个人资料](https://dev.dcloud.net.cn/pages/user/info) 绑定手机号。网页账号必须与 HBuilderX 一致，绑定由账号本人完成。
3. 工具 → 插件安装，安装官方 uni-app（Vue3）编译器及打包提示的依赖。本机已迁至 `C:/Users/yuzhi/HBuilderX`，uniapp-cli-vite、amazon-corretto、launcher、app-safe-pack 全部安装成功；此前目录权限问题已解决。
4. 发行 → 原生 App-云打包 → Android，包名 `com.huiyi.meetingdemo`；使用下述自有固定证书，关闭广告，不选自定义调试基座。
5. 成功后下载独立 APK，记录版本、签名与 SHA-256。`unpackage/dist/build/app-plus` 只是 App 资源，最终安装文件使用 `apk/` 内的 APK。

真实 DCloud AppID 为 `__UNI__0BBF9A7`，由本机已登录 HBuilderX 官方创建项目流程生成。初始版本 `0.1.0`，版本码 `100`。

## MuMu 安装与配置

1. 将最终 APK 拖入 MuMu，或使用其“安装 APK”功能，无需 ADB。
2. 开始录音时授予麦克风权限；MuMu 需能访问本机麦克风。
3. 不填模型配置也能录音、保存、重开查看和回放。初次先确认短录音声音正常。
4. 设置中输入**北京地域** Key 及对应 Workspace ID（只填 ID，不填网址）。配置仅在进程存活的本次会话有效，完整退出后需重填；后台进程未结束时仍保留在内存。
5. 配置完整且联网，正常录音保存后自动生成；已有录音在详情页点击“生成纪要”。同时最多一个请求，无自动重试。

模型固定 `qwen3.5-omni-plus`，接口固定：

```text
https://{WorkspaceID}.cn-beijing.maas.aliyuncs.com/compatible-mode/v1/chat/completions
```

生成会把整段音频发到阿里云并消耗额度。Key 不写入源码、应用本地存储或日志。Base64 和最终 JSON 请求体都必须严格小于 10,000,000 字节，超限保留原录音并提示，不切分或转码。

## 使用边界

- AAC/ADTS，单声道、16 kHz、24 kbps。设备是否接受参数、实际音质及 30 分钟大小仍待 MuMu/真机验证。理论约 5.4 MB 另加帧头，以实际文件为准。
- 保持应用在前台；切后台/锁屏时尝试停止保存，不承诺后台连续录音。系统杀进程后，下次启动尝试找回可读取临时音频，先回放确认完整性。
- 时长优先音频元数据，失败时按 AAC ADTS 完整帧计算；仍无法读取则显示“时长待读取”，播放获得后补存。
- 流式区域展示原始 JSON 增量，完整结束、校验并保存后显示分区纪要。断流不算成功。网络整体超时 10 分钟，文件读取另设 60 秒超时。
- 未执行真实模型调用，不保证识别准确性。金额、数量、负责人、日期和承诺需对照录音核对，未明确负责人/日期显示“未明确”。
- 云端实际产物包含 arm64-v8a、armeabi-v7a 两种原生架构，未包含 x86_64。MuMu 的 ARM 兼容运行及麦克风行为尚待实际安装验证。
